# SurveyBridge Web

Мини-приложение для подготовки результатов опроса к SPSS. Работает в браузере: выбранные файлы не отправляются на сервер. Это браузерная версия, без Python и Windows EXE.

## Использование

Откройте `dist/index.html` в современном браузере или разместите папку `dist` на статическом хостинге. Выберите Excel, CSV UTF-8 или Markdown-таблицу, проверьте предложенные типы переменных и задайте коды.

Поддерживаются открытые ответы String, числа, категории, бинарные ответы, индикаторы множественного выбора, даты и время. Есть настройка пропусков, групповое применение настроек, табличный просмотр, проверки диапазона/однообразия/запрещённых сочетаний и распределения с экспортом Excel/Word.

Комплект SPSS содержит `survey.xlsx` и `import.sps`. Распакуйте его в `C:\SurveyBridge` или измените строку `CD` в командах. Откройте `import.sps` в SPSS и выполните команды: они создадут `survey.sav`. Лист `Data` предназначен для просмотра; служебный `SPSS_Import` сохраняет String и ведущие нули с помощью маркера, удаляемого командами. Выполнение команд в установленном SPSS отдельно не проверено.

Сессия хранится в памяти вкладки. Сохраните нужные результаты и JSON-настройки перед обновлением страницы. Примеры реальных анкет в репозиторий не включены. Поддерживается до 20 МБ, 50 000 строк, 2000 столбцов, 2 млн ячеек; сложные файлы могут требовать меньшего объёма.

## Разработка и проверки

Нужен Node.js 22 или новее:

```sh
npm ci --ignore-scripts
npm run build
npm run check
npm audit --omit=dev
```

`npm run build` собирает docx и JSZip в браузерный bundle. SheetJS CE 0.20.3 взят с официального CDN и сохранён в `dist/vendor`; он не входит в npm audit. Версии и контрольные суммы указаны в `VENDOR.json`, лицензии библиотек — в `dist/vendor`.

GitHub Actions настроены для тестов, npm audit и CodeQL; Dependabot — для npm и Actions. Эти задания начнут выполняться после загрузки на GitHub, если Actions разрешены для репозитория. Тесты используют синтетические данные. Успешные проверки не являются сертификатом отсутствия вредоносного кода.

## Безопасность и ограничения

См. SECURITY.md и SECURITY_REVIEW.md. Код приложения не использует сетевые API или серверную загрузку файлов. CSP запрещает соединения и внешние скрипты. Обработка файла библиотекой всё равно имеет риски ошибок и чрезмерного потребления памяти. Проверки качества анкет не удаляют строки. Распределения не используют веса; индикаторы множественного выбора пока выводятся отдельно.

MIT распространяется на собственный код проекта; сторонние библиотеки сохраняют свои лицензии.
