# Security policy

Не публикуйте реальные анкеты, персональные данные и токены в issues, pull requests или примерах.

Для сообщения об уязвимости используйте приватное сообщение владельцу репозитория или private vulnerability reporting, если владелец включил его. В публичном issue описывайте только нечувствительные симптомы.

## Threat model

- Приложение читает выбранный пользователем файл и JSON-шаблоны, формирует файлы на скачивание.
- Обработка выполняется в памяти браузера. В собственном коде нет сетевой передачи файлов, учётных данных или телеметрии.
- JSON-шаблоны считаются недоверенными. Имена, режимы, шкалы и форматы SPSS проверяются перед экспортом.
- Пользовательские подписи экранируются перед выводом в HTML и включением в строки команд SPSS.
- CSV результатов проверки защищает строковые поля от интерпретации как формул Excel. В XLSX текстовые ответы записываются строками.
- Объём входных файлов ограничен; лимиты не исключают все варианты отказа в обслуживании, включая сложные сжатые файлы.
- CSP запрещает сетевые соединения и сторонние скрипты. CSP не заменяет проверку библиотек.

## Dependencies

Зависимости фиксируются lock-файлом. Vendored SheetJS проверяется отдельно: npm audit его не анализирует. Изменения `dist/vendor` требуют проверки происхождения, лицензии и контрольных сумм.

GitHub CodeQL, npm audit и антивирусы могут как пропускать проблемы, так и выдавать ложные срабатывания. Нулевое число предупреждений не доказывает безопасность. Этот репозиторий не является подтверждением безопасности ранее собранной Windows EXE.
