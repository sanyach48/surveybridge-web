# Проверка исходников — 1 ноября 2026

Проверена браузерная версия SurveyBridge. Это ограниченная проверка кода и зависимостей, не независимая сертификация и не антивирусное заключение о Windows EXE.

## Исправлено

- Добавлены разрешённые списки типов переменных, уровней измерения и форматов дат. Недоверенный JSON-шаблон больше не может подставить произвольный текст в эти позиции команд SPSS.
- Строковые значения в CSV результатов проверки нейтрализуют начальные символы формул Excel.
- CSP ограничена локальными скриптами и запрещает сетевые соединения.
- Добавлены ограничения размеров файла и таблицы.

## Проверено

- Собственный код приложения: нет отправки файлов через fetch/XMLHttpRequest/WebSocket/sendBeacon; данные не сохраняются на сервере.
- Строки интерфейса проходят HTML-экранирование; подписи в командах SPSS заключаются в кавычки с экранированием.
- Тесты проверяют 666 синтетических строк × 151 столбец, даты/время, пропуски, проценты, проверки анкет, String `001`, экспорт XLSX/DOCX/ZIP и блокировку подстановки команд через шкалу/формат.
- `npm audit --omit=dev` для фиксированных npm-зависимостей: 0 известных уязвимостей на момент проверки. Vendored SheetJS этим сканированием не покрывается.
- В публикацию не включены анкеты, EXE, токены, локальные пути пользователя и история служебного репозитория Sites.

## Ещё не выполнено
- Независимая антивирусная проверка и динамический анализ Windows EXE.
- Исполнение генерируемого синтаксиса в установленном SPSS.

Сторонние библиотеки и браузер остаются частью доверенной среды. Ограничения памяти не защищают от всех специально подготовленных архивов.
